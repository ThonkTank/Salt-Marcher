# Exportdialog: begrenztes UI-Paket

Der direkte Bildschirmbeleg aus Dungeondraft 1.2.0.1 [`20-export-modes.png`](/home/aaron/.cache/dungeon-native-qa/audit-20261004/karten-verwaltung/dd036-native-20261004-223413/evidence/20-export-modes.png) zeigt PNG, JPEG, WEBP und Universal VTT im Exportmodus. [`native-export-options.png`](/home/aaron/Schreibtisch/Obsidian/DnD%20OT/.obsidian/plugins/dungeon-auswertung/reference/native-export-options.png) zeigt außerdem Grid und Grid PPI. Damit sind die sichtbaren Bedienelemente für DD-043.02/.03/.14/.20–.22 belegt, nicht ihre vollständige Ausgabewirkung.

`src/features/verwaltung/export-dialog.ts` bietet einen eigenständigen Obsidian-Dialog für genau diese vier Formate, Raster an/aus und eine positive ganze Pixel-pro-Feld-Zahl. Die Integration übergibt den Startzustand ausdrücklich; das Modul behauptet keinen gemessenen Original-Default. Die Callback-Schnittstelle ist `onExport(request, signal) → { blob, filename }`. Erst nach erfolgreichem Callback erzeugt der Dialog einen Download mit dem gelieferten Dateinamen. Abbrechen, Escape und Schließen während eines laufenden Callbacks verhindern den Download und signalisieren Abbruch. Ein Fehler bleibt im Dialog sichtbar. Renderer, Menübefehl und tatsächliche Datei-/Pixelwirkung sind hier nicht implementiert und nicht am Host geprüft; DD-043.01/.19/.23 sind daher noch nicht abgenommen.

**Offene Original- und Produktgrenzen:** Lighting, Source Level und dessen Lighting, Brightness, Focus, Overlay Level/Lighting/Opacity, Camera Filter, Grid Presets, angezeigte Output pixel dimensions, Show in Folder on Finish sowie Crop/Reset Crop fehlen diesem schmalen Dialog. Ihre Optionen und Kartenwirkungen bleiben als DD-043.04–.13 und .15–.18 offen. Für Universal VTT sind Dateiinhalt, Wände, Türen und Licht separat zu prüfen. Es gibt noch keinen Beleg, dass die sichtbaren Optionen oder Ausgabedateien im Host Dungeondraft entsprechen.

Statisch geprüft: `npm run check`, gezielte Zahlenvalidierung und `npm run build`. Keine grafische Prüfung und keine Änderung an Main oder Vault.
