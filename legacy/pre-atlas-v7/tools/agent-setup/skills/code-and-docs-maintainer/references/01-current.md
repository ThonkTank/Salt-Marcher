# Vorhandene Aussagen aktuell halten

Lade den Fortschritt seit dem letzten abgeschlossenen Abgleich und die dadurch
betroffenen Aussagen. Gitänderungen sind Wegweiser; gezielter Code und passende
Testbelege entscheiden. Nicht alle Fachpläne oder den gesamten Statuskatalog lesen.

Wähle einen zusammenhängenden Bereich. Stimmen Verhalten, Grenzen,
Zuständigkeiten, Entwicklungs- und Prüfaufrufe noch? Ersetze überholte Aussagen
an ihrer maßgeblichen Stelle. Ein datierter Nachtrag unter altem Text erledigt
die Korrektur nicht. Aus Commitnamen, Testzahlen oder Teilbelegen keine neue
Fähigkeit oder allgemeine Freigabe ableiten.

Anforderungen sind Soll, Code ist Ist, native Qualifikation und Ownerabnahme
sind eigene Aussagen. Historische Originalbelege nicht umschreiben. Einen
Fortschrittszeiger nicht über ungeprüfte Änderungen hinwegsetzen; bei einem
größeren Bereich über mehrere vollständig abschließbare Aufträge fortsetzen.

Fertig: gewählte Aussagen belegt und widerspruchsfrei, Links/Prüfaufrufe korrekt,
eigener Änderungssatz geprüft und veröffentlicht. Neue Befunde oder ein neues
Datum allein genügen nicht.
