# SaltMarcher 0.2.0

Historical internal release candidate notes; this document is not public Electron
release acceptance. The planned first public Electron version is 0.3.0 under the
[maintenance roadmap](../project/architecture/release-maintenance-roadmap.md).

- Updates are checked in the app. Download and restart require explicit actions.
- Before installation, campaign data is backed up and migrated on a separate copy.
- Backups can be inspected and restored from Settings; current data is backed up first.
- Supported Electron profiles can be copied into the separate Release installation.
- Development and Local profiles remain separate. No Java-data import is included.

Installation schema 39 and campaign schema 34 are the frozen internal data baseline.
Later releases must preserve a complete forward migration path from this baseline.

Publication requires automated packaged upgrade qualification and an exact-artifact live
acceptance record covering update, saved campaign changes, continued play and restoration.
