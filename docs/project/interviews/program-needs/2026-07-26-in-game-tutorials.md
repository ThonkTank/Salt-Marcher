# In-Game Tutorials Follow-Up 2026-07-26

## Owner Requirement

> Alle capailities sollten per in-game tutorial erklärt werden.
>
> bei einer ersten installation oder nach einem update sollten tutorials
> automatisch beginnen, aber optional übersprungen werden können.

## Binding Behavior

Every capability exposed in the product is explained by an in-game tutorial.
Tutorials begin automatically on first installation and after an update. The
automatically begun tutorial experience is optional and can be skipped without
requiring the GM to finish it.

This evidence adds only that product behavior. Architecture, tutorial storage,
presentation, lesson content, update selection, sequencing, replay, and
implementation remain derived decisions rather than owner-confirmed evidence.
