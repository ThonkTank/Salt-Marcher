# Markttag als einfache Textnotiz

Diese Vergleichsaufgabe wurde hier manuell als Markdown geführt. Kein eigener
Obsidian-Lauf und keine menschliche Zeitmessung.

Vorher:

| Bestand | Seil | Heiltrank |
| --- | ---: | ---: |
| Hafenladen | 5 | 0 |
| Bergladen | 7 | 0 |
| Ada, ursprünglicher Fund | 4 | 0 |
| Borin | 0 | 2 |

Handel: Ada kauft **im Bergladen** ein Seil für insgesamt 5 GM. Borin verkauft
**an den Bergladen** einen Heiltrank für insgesamt 3 GM.

Nachher, manuell eingetragen:

| Bestand | Seil | Heiltrank |
| --- | ---: | ---: |
| Hafenladen | 5 | 0 |
| Bergladen | 6 | 1 |
| Ada, ursprünglicher Fund | 4 | 0 |
| Ada, zugekauft | 1 | 0 |
| Borin | 0 | 1 |

Verlauf: Ada, Kauf, Bergladen, ein Seil, gezahlt 5 GM.
Borin, Verkauf, Bergladen, ein Heiltrank, erhalten 3 GM.

In dieser Notiz bleiben Händler, Figur und betroffene Zeile sichtbar und explizit.
Das Produkt muss dieselbe Zuordnung auch während verzögerter Antworten einhalten.
Im Produkt schrieb je eine bestätigte Handelsaktion Shop und persönlichen Ledger
zusammen fort; die Textnotiz benötigt die getrennten Mengen-/Verlaufseinträge.
Die nativen Tests belegen diese eingesparte Buchführung und den Neustartbestand,
keine allgemeine Geschwindigkeitsüberlegenheit. Münzen bleiben gemäß Produktvertrag
manuell verwaltet.
