# Native selection probe

Read-only Dungeondraft 1.2.0.1 QA mod. Run it only in an isolated XDG profile with a temporary map. Activate `Codex.SelectionProbe`, then write `user://codex-selection-probe-request.json` with a unique request id, for example `{"id":"case-1","fixture":"pattern"}`. The process log prints one `CODEX_SELECTION_PROBE` snapshot containing the active filters, drag-box coordinates and selected entity types. The optional `fixture` is only a label.

The probe does not perform input, change the selection or save maps. Compare its world-space box coordinates with the intended gesture before interpreting a negative selection result. On the software-rendered virtual display, synthetic pointer moves sometimes reach the application late or begin an object drag instead of a marquee.

For isolated TigerVNC QA, `rfb_drag_probe.py` sends one stepped drag and captures the read-only state before, while held, and after release. Pass the active profile's `user://` request file through `--request`, Dungeondraft's output log through `--log`, unique `--id`, and screen pixel coordinates through `--start` and `--end`. It rejects an id already present in the active log, preventing stale snapshots. It also refuses a nonempty selection unless `--allow-selection` is set for transform probes. Treat the result as a marquee measurement only when the held snapshot reports `is_drawing=true` and the saved map or screenshot confirms unchanged element geometry. The native snapshot includes `transform_mode` and `transform_corner` for selected-object grip probes.

Use `--steps` to vary pointer-event spacing and `--hold-seconds` to wait at the endpoint before the held snapshot. On the measured PatternShape, the selected set and held `box_end` trailed the final cursor by roughly one movement step; after release, `box_end` reached the cursor but the selection did not change. A longer stationary hold did not remove the lag. Report the held box and step count alongside the released selection; do not infer a fixed geometry margin from the cursor endpoint alone.
