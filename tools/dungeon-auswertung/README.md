# Phase-6-Adapter der Auswertung

`ui.js` ist die Phase-6-Fassung des gleichnamigen Quellmoduls von `dungeon-auswertung`. Es liest V4-Raumtexte aus dem Dungeon-Editor als virtuelle Dokumente und führt Berichts-Quellsprünge zu den stabilen Raum-Keys. Der bestehende Format-2-Rechenkern und die Berichtsdarstellung bleiben erhalten.

Für einen erneuten Build `ui.js` in den Quellordner von `dungeon-auswertung` übernehmen und dort `node build.js <Ausgabepfad>` ausführen. Die installierte Plugin-Datei wird erst nach Sicherung und dem Phase-6-Abnahmelauf ersetzt.
